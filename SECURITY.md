# Security Policy

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal data, or sensitive repository content in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is available. If it is unavailable, contact the repository owner through the [GitHub profile](https://github.com/shaheer51-1) and ask for a private reporting route. Include only the minimum detail needed to reproduce the issue, and do not attach secrets.

## Scope

This policy covers the NEX source code and included utilities. Third-party AI clients, model providers, and hosting platforms have their own security reporting processes.
